# Charging Under Chaos

An interactive page asking what it costs to charge 5,000 electric cars at the cheapest times
when the car and charger makers' online systems are unreliable.

- Real electricity prices: Octopus Agile (London) and Elexon, September 2026.
- Everything else is simulated: the cars, four made-up companies with invented failure rates,
  and control software written for this project. No real car or company was involved.

Everything is in `index.html`. The results are inlined and the page makes no network requests.

Independent project. Company names are fictional.
